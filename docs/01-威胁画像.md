# 威胁画像：领鸡蛋骗局怎么搬到了手机上

> 本文是规则库与评分模型的依据。所有特征都来自公开通报与权威媒体报道，标注在文末。
> 文中不出现任何可直接访问的涉诈网址 —— 那既会过期，也会被二次利用。

---

## 一、两条主线，一个内核

「领鸡蛋」是入口，不是骗局本身。往前一步，它分叉成两条完全不同的收割路径，而这两条路径在线上化之后共用同一套基础设施。

### 主线 A：保健品会销（线下为主，线上加速）

```
社区/菜市场发传单 → 免费领鸡蛋、米面油 → 健康讲座（租酒店会议室）
→ "专家"义诊、夸大病情 → 交 100 元诚意金、次日全额退还（建立信任）
→ 活动升级，几千到几万元"套餐" → 不再退款，改送"收藏品"
→ 门店注销、人员失联
```

关键机制是**「确定性小利」换「不确定性大额」**：前几天的鸡蛋和退款是真实兑付的，这会在老人心里建立一个错误前提 —— 「这家公司说话算数」。之后的每一次加码都建立在这个前提上。

2026 年 10 月央视公布的典型案例中，这类团伙已高度职业化：「老板团」幕后操控、「流动专家团」冒充名医教授、「门店业务员」负责引流，形成「老板操控、讲师授课、门店收割」的产业链。一个案子抓获 120 人，涉案 500 余万元。

### 主线 B：仿冒「国家项目」App（线上为主，危害更大）

```
短视频/微信群看到"国家发补贴" → 扫码或点链接下载 App（应用商店搜不到）
→ 实名注册、人脸识别、绑定银行卡 → 领到 8-28 元/天签到补贴
→ 被告知"补贴要激活/缴税/交保证金" → 转账
→ 或被引导"跟投项目""认领资产"，投入养老钱 → 平台数据清零、跑路
```

这条线的单案金额远高于 A。2026 年 9 月公安部通报的吉林案件，团伙编造「复兴汇金」「养老行动」等虚假国家项目，雇佣技术团队开发涉诈 App，涉案金额超 60 亿元，抓获 257 人。

**两条线的交汇点**：都靠「免费/补贴」建立初始信任，都用微信群做裂变，最终都要求向**个人账户或虚拟货币地址**转账。

## 二、线上化的载体矩阵

| 载体 | 典型形态 | 可观测特征 | 采集难度 |
| --- | --- | --- | --- |
| **APK** | 仿冒「中国养老」「国惠民生」「快手银发」 | 商店搜不到、无备案、签名证书固定、模板指纹复用 | 低（拿到文件即可静态分析） |
| **落地页** | 单页 H5，只有"点击下载" | 域名新、免费托管、强制下载、引导关闭安全检测 | 中（只查被动情报，不访问） |
| **微信小程序** | 「惠民补贴申领中心」类 | 主体多为个体工商户、类目与功能不符 | 高（无公开接口，需人工） |
| **公众号** | 发布"政策解读"伪造成官方 | 认证主体与宣称身份不符、历史文章批量搬运 | 高（需人工） |
| **微信群** | 群托晒收益、老师带单 | 群名含"福利""惠民""圆梦"、每日签到红包 | 极高（端到端加密） |
| **短视频账号** | 讲解"国家新政"引流私信 | 头像用国徽/红头文件、评论区引导加微信 | 中（平台内举报） |

**结论**：APK 是唯一可以规模化、自动化、且证据强度足够高的载体。这也是本系统把 APK 静态分析做成核心能力的原因。

## 三、七步剧本（可直接用于劝阻）

| 阶段 | 骗子动作 | 老人的感受 | 可观测信号 |
| --- | --- | --- | --- |
| 1. 引流 | 免费领鸡蛋、扫码进群领红包 | "占了便宜" | 「免费领」「到场即送」「扫码进群」 |
| 2. 筛选 | 登记手机号、身份证、住址 | "正规，要登记" | 「实名认证」「身份证正反面」 |
| 3. 建信 | 每日签到发 8-28 元、群托晒到账 | "真的给钱" | 「每日签到」「收益截图」「已到账」 |
| 4. 升维 | 抛出"国家项目""民族资产解冻" | "这是国家给的" | 「国家项目」「民族资产解冻」「国补」 |
| 5. 加码 | 缴税/保证金/激活费才能提现 | "就差一步" | 「解冻费」「保证金」「个人所得税」 |
| 6. 收割 | 引导大额转账、USDT 充值 | "再投就能回本" | 「USDT」「TRC20」「个人账户」 |
| 7. 消失 | 数据清零、群解散、换皮上线 | "再等等" | 域名/包名更换，但模板指纹不变 |

第 3 步是整个骗局的**枢纽**：它把"陌生人"变成"给我发过钱的人"。劝阻的黄金窗口在第 3 步到第 4 步之间 —— 此时老人还没投入大额，但已经建立了信任，需要的是**证据**而不是说教。

## 五、技术指纹（APK）

拿到安装包后，按「换皮成本」从高到低看：

| 指纹 | 稳定性 | 说明 |
| --- | --- | --- |
| **签名证书 SHA-256** | 极高 | 换证书等于换开发者身份，成本最高，是团伙归并的首选锚点 |
| **包名前缀** | 高 | `com.xxx.yyy` 的前两段常被复用 |
| **assets 页面模板** | 高 | H5 落地页的 DOM 结构 simhash，换域名不换模板 |
| **收款钱包地址** | 极高 | 硬编码在 dex 或配置里，改地址要重新分发 |
| **权限组合** | 中 | READ_SMS + 无障碍 + 悬浮窗 + 安装应用，这套组合在正常 App 里极少见 |
| **加固壳特征** | 中 | libjiagu / libshell / libDexHelper，说明刻意对抗分析 |
| **包名全称** | 低 | 一天能生成几百个 |

`REQUEST_INSTALL_PACKAGES` 权限尤其值得注意：**请求安装其他应用**（`REQUEST_INSTALL_PACKAGES`）意味着它可以自己下发马甲包，一个装上了，后面会源源不断。

## 六、受害人画像

不是「贪小便宜」四个字能概括的。公开案例反复指向同一组结构性因素：

- **有退休金但现金流焦虑**：一笔几万元的支出需要"理由"，而"国家补贴"提供了一个体面的理由。
- **独居或子女不在身边**：业务员每天上门陪聊、叫"干妈"，填补的是情感缺口，不是钱包缺口。
- **有慢性病**：「根治三高」击中的是对疾病的恐惧，不是对金钱的贪婪。
- **信息渠道单一**：短视频和微信群是主要信息源，缺少交叉验证的能力与习惯。
- **羞耻感强**：被骗后不愿告诉子女，导致追赃窗口错过。这一点直接决定了处置话术必须**去指责化**。

## 七、为什么常规手段打不干净

1. **成本不对称**：一套模板 + 一个新域名 + 一次重打包，成本几百元；而立案、取证、跨省抓捕的成本是数量级差异。
2. **证据在被害人手里**：安装包、聊天记录、转账凭证都在老人手机上，老人不报案，证据就不存在。
3. **平台责任边界模糊**：应用商店管不到侧载，运营商人能关域名但关不掉已安装的 App。
4. **定性门槛**：保健品夸大宣传归市场监管（行政处罚），集资诈骗归公安（刑事），中间地带常被当作"消费纠纷"处理。

所以真正有效的干预点只有两个：**在安装前拦住**（识别 + 家属沟通），**在转账前拦住**（96110 + 银行止付）。本系统的全部设计都指向这两个时点。
