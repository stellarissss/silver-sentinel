# 处置手册：报给谁、怎么报、怎么劝

> 这一篇是给家属、社区工作者、网格员用的。不需要懂技术，按顺序做即可。

---

## 一、先判断：现在处在哪一步

处置方式取决于老人已经走到哪一步，而不是取决于"这个东西多可疑"。

| 现状 | 紧急度 | 首要动作 |
| --- | --- | --- |
| 只是看到广告、还没下载 | 低 | 讲清楚套路，不要扫码 |
| 已安装 App，还没投钱 | 中 | 卸载 + 检查权限 + 改密码 |
| 已投小额，还在"签到领钱" | **高** | 立即停止追加，保留证据，报警咨询 |
| 已投大额，或被要求"缴税才能提现" | **极高** | 立刻 96110 / 110 + 银行止付 |
| 已被要求屏幕共享 / 远程协助 | **极高** | 立刻断网、关机、挂失银行卡 |

**判断依据**：只要出现「先交钱才能领钱」「提现要缴税」「充值用 USDT」「转账给个人账户」任意一条，不需要再验证，直接按最高级别处理。

## 二、报给谁：渠道对照表

不同渠道管不同的事，报错地方等于没报。

| 渠道 | 入口 | 管什么 | 什么时候用 |
| --- | --- | --- | --- |
| **96110** | 电话直拨 | 反诈预警、紧急劝阻 | 正在转账、已被深度洗脑、需要上门劝阻 |
| **110** | 电话直拨 | 刑事案件 | 已经转账、金额较大 |
| **12321** | [12321.cn](https://www.12321.cn) / 「12321 举报助手」App / 微信公众号 | 不良 App、诈骗网址、垃圾信息 | 举报仿冒 App 与落地页（**首选**） |
| **12377** | [12377.cn](https://www.12377.cn) | 违法和不良信息、冒充国家机关 | 网页/账号冒充政府、传播虚假政策 |
| **网络违法犯罪举报网站** | [cyberpolice.cn](https://www.cyberpolice.cn) | 涉网犯罪线索 | 已造成损失，需要留痕与查询进度 |
| **12315** | [12315.cn](https://www.12315.cn) | 消费欺诈、虚假宣传 | 保健品宣称疗效、会销不退款 |
| **12345** | 电话直拨 | 政务服务咨询 | 反向核实"有没有这个补贴项目" |
| **域名注册商 abuse** | whois 里的 abuse 邮箱 | 关停域名 | 要求下架仿冒站点 |
| **应用商店/平台** | 各平台举报入口 | 下架应用、封号 | App 在商店上架了（少见但存在） |

### 举报时的三个要点

1. **一个对象一份材料**。不要把五个域名写在一份举报里，受理系统按对象分派。
2. **附原始证据，不要只写描述**。"它骗人"没用，"它要求我转账到 XX 个人账户，聊天记录如下"才有用。
3. **记下受理编号**。后续催办、并案都靠它。

## 三、材料要素清单

一份能被受理的举报，包含这六项：

```
1. 被举报对象    网址 / App 名称 / 包名 / 公众号名称（尽量给唯一标识）
2. 发现时间      首次看到的时间与途径（谁转发、哪个群、哪个视频）
3. 事实经过      按时间顺序，谁在什么时间说了什么、要求做什么
4. 证据          截图（含时间）、聊天记录、转账凭证、安装包、录音
5. 诉求          要求核查 / 下架 / 关停 / 并案
6. 联系方式      实名举报需留真实联系方式（受理方会保密）
```

本系统可以直接生成这份材料：

```bash
silver-sentinel report <线索ID> --channel 12321 --out 举报材料.md
```

或在控制台「线索详情 → 处置 → 生成举报材料」，支持 12321 / 12377 / cyberpolice / 12315 / 96110 / 注册商六种模板，每份都带证据哈希清单。

## 四、常用法条（可直接写进举报材料）

| 法条 | 内容要点 | 适用场景 |
| --- | --- | --- |
| 《刑法》第二百六十六条 | 诈骗公私财物，数额较大的构成诈骗罪 | 已骗取钱财 |
| 《反电信网络诈骗法》第三十八条 | 禁止非法制造、买卖、提供、使用用于实施电诈的设备与软件 | 开发、分发涉诈 App |
| 《广告法》第十七条 | 非医疗、药品、医疗器械广告不得涉及疾病治疗功能 | 保健品宣称治病 |
| 《食品安全法》第七十三条 | 食品广告不得涉及疾病预防、治疗功能 | 普通食品当"特效药"卖 |
| 《禁止传销条例》第七条 | 以发展人员数量计酬、要求交纳费用取得加入资格属传销 | 拉人头返利 |

> 引用时以现行有效文本为准。不确定条号时，只写法规名称与规范内容，不要编造条号 —— 一份引错法条的举报材料会削弱整份材料的可信度。

## 五、怎么劝：分场景话术

劝不动的根本原因通常不是"老人糊涂"，而是**你在攻击他的判断力，而骗子在维护他的尊严**。所以话术的第一原则是：**不说"你被骗了"，说"我们一起看看"。**

### 场景 1：刚开始领鸡蛋，还没花钱

> "妈，这个鸡蛋您拿着吃。我就是好奇，他们登记您身份证了吗？……登记了呀。那您帮我个忙，下次去的时候问问他们公司全名叫什么，我查一下是不是正规注册的。"
>
> （目的：不否定，先建立"共同调查"的姿态。）

### 场景 2：已经下载了 App，坚信能领到钱

> "您先别投钱，就继续签到领那几块钱，看它给不给。真给，说明它舍得下本；但它越舍得，后面要的越多。咱们就领它的小钱，一分不投，行不行？"
>
> （目的：不争夺"真假"的判断权，而是把行为约束在"只领不投"。这是最容易达成的共识。）

### 场景 3：已经被要求转账"激活"

> "这个钱我来转，您把账号给我。" —— 拿到账号后，直接报警，不要转。
>
> 或者："我同事上个月也遇到一模一样的，后来派出所说是诈骗。咱们先去问一下，问错了不损失什么，问对了能保住钱。"

### 场景 4：已经转了钱，不肯承认

> "这不是您的错，这套话术是专门研究过怎么让人相信的，很多退休教师、医生也上当了。现在最重要的不是钱，是别让他们再用您的身份去贷别的款。咱们先去银行查一下。"
>
> （目的：去羞耻化。羞耻感是追赃最大的敌人。）

### 三个绝对不要说的话

- ❌ "你怎么这么糊涂" —— 激活防御，之后的沟通全部失效
- ❌ "早就跟你说过" —— 把重点从"止损"转移到"认错"
- ❌ "以后钱都我管" —— 剥夺自主权，老人会转入地下，反而更难发现

## 六、已经转账了：黄金 30 分钟

1. **立刻拨 96110 或 110**，说明：转账时间、金额、对方账号、对方开户行。
2. **联系开户行申请紧急止付**，越早冻结成功率越高（资金通常在被骗后几分钟内被分散转移）。
3. **保留一切**：不要删聊天、不要卸载 App、不要恢复出厂设置。App 本身就是证据。
4. **修改密码**：银行卡、支付软件、社保账号。若做过人脸识别，联系银行做账户安全锁定。
5. **查征信**：确认没有被冒名贷款（人民银行征信中心官网可查）。
6. **报案回执**：拿到受案回执，这是后续追赃和并案的凭据。

## 七、拆掉手机里的"雷"

已确认安装的涉诈 App，按顺序处理：

```
设置 → 应用管理 → 找到该应用
  1. 先看权限：关闭「无障碍服务」「悬浮窗」「读取短信」「读取通讯录」
  2. 再看「设备管理器」：如果已激活，先取消激活（否则无法卸载）
  3. 卸载
  4. 检查「未知来源应用安装」是否被打开，关掉
  5. 检查是否还有其他不认识的 App（这类团伙常一次装多个）
```

iOS 相对简单：长按图标删除，再到「设置 → 通用 → VPN 与设备管理」移除描述文件。

## 八、如果举报后没有回音

这是常态，不是失败。可以做三件事：

1. **补材料再提交**：同一对象补充新证据，注明原受理编号，要求并案。
2. **走属地渠道**：12321 是全国口径，属地网信办（如 `www.xx12377.cn`）处理更快。
3. **联合举报**：同一个群里的其他家属一起报，案件并案的概率显著提高。

---

## 九、把这件事变成可持续的

单次劝阻救一个人，机制才能救一群人：

- 在家庭群里固定发一次「本周新套路」，比临事说教有效十倍。
- 给老人手机装「国家反诈中心」App 并**开启来电预警**（装了不开等于没装）。
- 和父母约定一个"大额支出前必须打电话"的规则，理由是"帮我看一眼合同"，不是"怕你被骗"。
- 社区层面：把本系统的「给家属的一页纸」打印出来贴在公告栏，比贴标语有用。

```bash
silver-sentinel report <线索ID> --bundle --out bundle.json   # 含一页纸
```
