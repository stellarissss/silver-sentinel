# 浏览器缺失导致的重启死循环根治（v1.16.15）

日期：2026-11-24

## 现象

新机 `43.143.3.160` 的 silver-sentinel 陷入崩溃重启循环：每分钟重启一次，
`systemctl show silver-sentinel -p NRestarts` 显示 **358 次**重启，白烧 CPU。
日志固定为：

```
连续 3 次浏览器不可用，进程已无法自愈，主动退出等待 systemd 重启
```

同时 `PLAYWRIGHT_BROWSERS_PATH` 指向的 `/opt/silver-sentinel/ms-playwright/`
是空目录，Chromium 从未装上。

## 根因（三层，缺一不可）

| 层 | 问题 |
| --- | --- |
| 部署 | wheel 未携带 `sandbox` extra，venv 里 `pip list` 无 playwright；`install.sh` 遇到 playwright 缺失/Chromium 装不上只 `warn` 放过，留下「能启动、能开网页、但每次取证都失败」的半残服务 |
| 取证 | `_note_browser_failure` 把所有「浏览器不可用」一视同仁；真正的 `ModuleNotFoundError: No module named 'playwright'` 是**永久性**故障，重启进程永远不会自愈 |
| 服务 | systemd `Restart=always` + `RestartSec=5` 把 `os._exit(3)` 放大成无限重启风暴 |

一句话：**把「没装浏览器」（重启无用）误判为「进程毒化」（重启可自愈）**，
于是重启成了唯一的「自愈」手段，却永远修不好。

## 修复（v1.16.15）

### 1. 取证层：错误分型 + 长冷却降级（`capture.py`）

- 新增 `_is_permanent_browser_error(text)`：按错误文本识别「浏览器运行时未安装」
  类永久性故障（`ModuleNotFoundError: playwright`、`Executable doesn't exist`、
  `playwright install chromium` 等）。
- `_note_browser_failure(text)`：
  - **永久性故障** → 进入 1 小时长冷却（`_BROWSER_DOWN_UNTIL`），告警一次
    （`capture.browser_missing`），**绝不 `os._exit`**；冷却期满自动重试，
    补装后无需重启进程即可恢复。
  - **进程级毒化**（asyncio loop / different thread）→ 保留原 `os._exit(3)` 重启自愈。
- `capture_asset()` 入口检测降级态，直接短路返回带修复指引的失败，不再拉起浏览器。
  服务与 Web 页面全程在线。

### 2. 浏览器层：import 错误可判别（`sandbox/web.py`）

把 `from playwright.sync_api import sync_playwright` 移进 `try` 块，让"没装包"的
`ModuleNotFoundError` 也被统一包装成带 `playwright install chromium` 提示的错误文本，
确保能被上层分型识别。

### 3. 部署层：fail-fast（`deploy/install.sh`）

- playwright 缺失时自动补装；补装失败即 `die`，不再放过。
- Chromium 安装失败或装完找不到可执行文件即 `die`，杜绝半残服务上线。
- 就位判断从「目录非空」升级为「目录非空 **且** 找到 chrome/headless_shell 可执行文件」。
- Chromium 下载改为「npmmirror 镜像优先、官方源回退」，两路都加 `timeout 600` 上限：
  新机实测官方 CDN 卡 9 分钟无进度，镜像 37 秒下完 125MB，彻底避免部署被拖死。

## 运维：补装浏览器（无需改代码）

```bash
cd /opt/silver-sentinel
PLAYWRIGHT_BROWSERS_PATH=/opt/silver-sentinel/ms-playwright \
  .venv/bin/python -m playwright install chromium
chown -R sentinel:sentinel /opt/silver-sentinel/ms-playwright
# 降级态最多 1 小时后自动恢复；想立即恢复可 systemctl restart silver-sentinel
```

## 验证

- 新增 `tests/test_browser_missing_degradation.py`：13 个用例覆盖分型、降级不退出、
  可恢复错误仍退出、降级短路。
- 全量测试：**600 passed**；ruff 全绿；`install.sh` bash 语法通过。
